# Personal Website

This is the repo for my personal website.

Originally, this was going to be the frontend for a journaling website that I wanted to develop, but I never followed up with it. A year later, I decided to revisit this repo, and asked myself, "why not just turn it into your personal website?" And so I did.

I'm sure that several software engineers have their own websites where they can showcase their skills and offer people a little bit of their personality, and I figured that I might as well jump onto the bandwagon. So, here it is, my personal website.
